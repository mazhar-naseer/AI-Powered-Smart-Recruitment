## Bug: Resume Analysis Fails for Multiple Applicants

**Module:** Job Application / Resume Analysis
**Severity:** High
**Status:** Open

**Steps to Reproduce:**

1. Apply for the same job using different applicant accounts with different CVs.
2. Submit applications from multiple accounts.
3. Check the resume analysis results.

**Expected:** Each applicant should receive their own resume analysis, match score, and AI feedback.

**Actual:** After multiple applicants apply for the same job, resume analysis shows an error, and the match score and AI feedback are not displayed.
